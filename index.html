專題動機

傳統置物櫃靠鑰匙或密碼鎖，鑰匙會遺失、密碼會外流，管理者也難以得知誰在何時使用。好櫃櫃用低成本的 ESP32 整合多種身分驗證，並提供網頁後台，讓置物櫃管理更安全、更方便。

鑰匙會弄丟

RFID 卡片與指紋取代實體鑰匙，管理者可隨時新增或停用授權。

密碼會外流

指紋是每個人獨有的，無法借用或轉傳，降低盜用風險。

管理很麻煩

透過手機瀏覽器即可登錄、刪除指紋，並即時看到辨識紀錄。

系統功能

所有功能由一塊 ESP32 開發板統一控制。

RFID 刷卡開鎖

以 MFRC522 讀取卡片 UID，與白名單比對；符合即驅動舵機開鎖，不符則亮紅燈並響起蜂鳴器警示。

指紋辨識（AS608）

可儲存 1～127 枚指紋，辨識成功自動開鎖，並回報指紋 ID 與相似度。

網頁遠端管理

ESP32 內建網頁伺服器，手機連上同一 Wi-Fi 即可使用，需輸入帳號密碼登入。

OLED 即時顯示

以 0.96 吋 OLED 顯示 LOCKED / UNLOCKED 與操作提示。

觸摸控制燈光

觸摸感應模組搭配繼電器，輕觸一下即可開關櫃內燈光，含防彈跳處理。

聲光回饋

綠燈代表通過、紅燈代表拒絕，蜂鳴器提示結果；蜂鳴器以軟體方波驅動，避免與舵機搶用 PWM。

運作流程

不論用哪一種方式，都走同樣的驗證流程。

  1. 1. 提出身分刷卡或按上指紋
  2. 2. 比對授權卡片白名單／指紋資料庫
  3. 3. 驅動鎖具通過：舵機轉到開鎖角度
  4. 4. 回饋與紀錄OLED、燈號、蜂鳴器、網頁同步更新
  5. 5. 自動上鎖延遲後舵機回到鎖上位置

網頁管理介面

管理者用手機就能操作，不需要另外安裝 App。畫面每秒自動更新。

  • 即時顯示 AS608 連線、門鎖狀態、燈光狀態
  • 顯示已登錄的指紋數量
  • 查看最近一次辨識的來源、指紋 ID 與相似度
  • 新增指紋：依畫面提示放上手指、移開、再放同一根手指
  • 刪除指定 ID，或一鍵清除全部指紋
  • 操作需通過帳號密碼登入，避免外人改動授權名單
